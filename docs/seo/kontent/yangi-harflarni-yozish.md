# Ş, Ç, Ğ, Ö ni qanday yozish mumkin

**Qisqa javob:** uch yo'l bor. **1)** Klaviaturaga tugmada ö ğ ş ç beradigan tartib qo'shish (masalan, Windows
va Mac'ga o'rnatilgan «Turkish Q»). **2)** Telefonda harfni bosib turish. **3)** Eskicha yozib, so'zni avtomatik
o'girish — Windows'da **bitg** shuni qiladi: «choy» yozasiz, probeldan keyin «çoy» chiqadi.

## Windows

### 1-yo'l: bitg (tavsiya)
1. [bitg'ni yuklab oling](/yuklab-olish/) va o'rnating.
2. **Win + Probel** bilan «bitg» klaviaturasini tanlang.
3. Odatdagidek yozing: `o'zbek`, `shahar`, `choy` → probeldan keyin `özbek`, `şahar`, `çoy`.

Tugma bilan yozishni afzal ko'rsangiz, sozlamalarda «Yangi harflar tugmada» yoqiladi. Standart tartibda:
`[` → ö, `]` → ğ, `;` → ş, `'` → ç, `` ` `` → ʼ (tutuq). Ikkinchi tanlov — Turkcha Q, uchinchisi — o'ng Alt +
O/G/S/C.

### 2-yo'l: Turkish Q (qo'shimcha dastursiz)
Sozlamalar → Vaqt va til → Til → Turkcha qo'shing → klaviatura «Turkish Q». Bunda `[` ğ, `;` ş, `,` ö, `.` ç
beradi, lekin vergul va nuqta joyi o'zgaradi, `i` tugmasi esa nuqtasiz `ı` yozadi — o'zbekcha uchun noqulay.

### 3-yo'l: Word'da kod bilan
Word'da harf kodini yozib **Alt + X** bosing: `00F6` → ö, `011F` → ğ, `015F` → ş, `00E7` → ç
(bosh harflar: `00D6`, `011E`, `015E`, `00C7`).

## Mac
- **Turkish Q** tartibi: System Settings → Keyboard → Input Sources → «+» → Turkish Q.
- ABC tartibida: **Option + U**, keyin **O** → ö; **Option + C** → ç. Ş va Ğ uchun Turkish Q yoki maxsus
  tartib qulayroq. *(TODO: haqiqiy Mac'da tekshirib skrinshot)*

## Linux / Ubuntu
- Settings → Keyboard → Input Sources → «Turkish (Q)» qo'shish.
- Yoki Compose tugmasini yoqib: `Compose " o` → ö, `Compose , s` → ş, `Compose , c` → ç, `Compose U g` → ğ.
- bitg'ning Linux versiyasi (IBus/Fcitx5, `.deb`) — rejada.

## Android
- Ko'p klaviaturalarda harfni bosib tursangiz, variantlar chiqadi: **o** → ö, **c** → ç, **s** → ş, **g** → ğ.
- Chiqmasa: Gboard → Sozlamalar → Tillar → «Turkcha» qo'shing va probeldagi globus bilan almashtiring.
