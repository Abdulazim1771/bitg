Edge (Caddy), 301 yo'naltirish va saytni bitg.uz'ga o'tkazish
Claude30 daqiqa
DNS ishlagach menga ayting: «bitg.uz ni edge'ga ula va saytni ko'chir». Men qilaman:
  • dtwin edge'ga bitg.uz bloki (HTTPS sertifikat avtomatik), www.bitg.uz → bitg.uz;
  • bitg.dtwin.uz/* → bitg.uz/* doimiy (301) yo'naltirish;
  • saytdagi canonical, og:url, sitemap, robots.txt → bitg.uz; llms.txt qo'shish; deploy;
  • tekshiruv: curl -I https://bitg.dtwin.uz/ → 301 → bitg.uz.
dtwin edge faqat dtwin repo deploy orqali o'zgartiriladi — serverda qo'lda tahrir qilinmaydi.

2. Google Search Console

Google — O'zbekistonda qidiruvning ~75–78%. Asosiy panel.

Domenni Google'da tasdiqlash
Siz10 daqiqa
  1. search.google.com/search-console → Google akkauntingiz bilan kiring.
  2. Add property → chap tomondagi Domain → bitg.uz → Continue.
  3. Google google-site-verification=... ko'rinishidagi TXT yozuv beradi → nusxalang.
  4. Registrator DNS panelida: turi TXT, nomi @, qiymati — o'sha matn. Saqlang.
  5. Search Console'ga qaytib Verify. «Topilmadi» desa — 15–60 daqiqadan keyin qayta bosing.
«Domain» turi www, http va https'ning hammasini birdan qamraydi — eng to'g'ri tanlov.
